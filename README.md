# Recieptify

Recieptify is a lightweight web application designed to help small business owners turn raw receipt and invoice text into an actionable verification checklist.

## Features

- **Text Parsing:** Parses unstructured receipt and invoice text.
- **Categorized Audit Breakdown:** Organizes information into four categories:
  - Vendor Info
  - Line Items
  - Payment Terms
  - Risk Flags
- **Interactive Checklists:** Allows users to check items during manual auditing and record verification.

## Technology Stack

- HTML
- CSS
- JavaScript

## Project Scope

The initial version focuses on processing raw text rather than uploading PDF files directly. This keeps the first version simple and lightweight while the core parsing functionality is developed.

## Current Development Focus

- Parsing receipt and invoice text.
- Organizing extracted information into useful audit categories.
- Supporting manual verification through interactive checklists.

## Future Improvements

- Explore direct PDF upload and parsing.
- Test the parser against different receipt and invoice formats.
- Improve the accuracy of categorization and verification.

## Project Status

Recieptify is under development. Features and functionality will be documented as they are implemented and tested.
